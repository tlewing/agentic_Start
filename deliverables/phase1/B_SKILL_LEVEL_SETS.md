# GSL Academy - Skill Level Sets

## Overview

Skill Level Sets define the progression path for GSL employees from entry-level to senior leadership. Each level builds upon the previous, with specific training and certification requirements.

---

## Skill Level Framework

### Level 0: Pre-Employment

| Attribute | Value |
|-----------|-------|
| **Level ID** | L0 |
| **Level Name** | Pre-Employment |
| **Typical Role** | Applicant |
| **Prerequisites** | None |
| **Training Focus** | None required |
| **Certification** | None |

---

### Level 1: New Hire / First Year Apprentice

| Attribute | Value |
|-----------|-------|
| **Level ID** | L1 |
| **Level Name** | Entry Level |
| **Typical Role** | Apprentice Electrician (Year 1) |
| **Prerequisites** | Hired by GSL |
| **Training Focus** | Safety orientation, basic electrical theory, hand tools, EMT conduit |
| **Certification** | New Hire Safety Orientation complete |

**Technical Skills Expected (End of Year 1):**
- DC calculations (Ohms Law, Power Equation)
- Knowledge of batteries and electrical energy sources
- Nominal AC voltages (single and three phase)
- Familiarity with electrical parts and ordering
- Panel board understanding (system/equipment grounds)
- EMT conduit bending with hand benders
- Use of testers (wiggins, continuity, ammeters)
- Wire pulling up to #2
- 3-way and 4-way switching

---

### Level 2: Second Year Apprentice

| Attribute | Value |
|-----------|-------|
| **Level ID** | L2 |
| **Level Name** | Developing |
| **Typical Role** | Apprentice Electrician (Year 2) |
| **Prerequisites** | L1 complete, 2000 field hours |
| **Training Focus** | Rigid conduit, motor controls, blueprint reading, AC theory |
| **Certification** | None additional |

**Technical Skills Expected (End of Year 2):**
- Rigid conduit installation with hand benders
- Simple motor control wiring (stop/start)
- Blueprint reading (circuit info, elevations, details)
- Wire rigging and pulling up to 4/0 MCM
- All conduit systems up to 2"
- AC waveform understanding
- Inductance, capacitance, power factor, voltage drop, KVA/KW
- Single phase and 3 phase load hookup
- Basic overcurrent protection
- Basic transformer familiarity

---

### Level 3: Third Year Apprentice

| Attribute | Value |
|-----------|-------|
| **Level ID** | L3 |
| **Level Name** | Proficient |
| **Typical Role** | Apprentice Electrician (Year 3) |
| **Prerequisites** | L2 complete, 4000 field hours |
| **Training Focus** | NEC code, advanced testing, motor controls, medium voltage |
| **Certification** | None additional |

**Technical Skills Expected (End of Year 3):**
- All sizes of conduit systems
- All types/sizes of wire and cable
- NEC knowledge (conductor sizing, conduit fill, box fill, grounding, overcurrent)
- Reading risers, schedules, details, cross-referencing drawings
- Multi-meters, meggars, advanced testers
- Motor controls and simple instruments
- 5kV-15kV terminations and splices
- High voltage safety considerations
- Setting/terminating 600V and 5kV-15kV gear, transformers, motors

---

### Level 4: Fourth Year Apprentice

| Attribute | Value |
|-----------|-------|
| **Level ID** | L4 |
| **Level Name** | Advanced Apprentice |
| **Typical Role** | Apprentice Electrician (Year 4) |
| **Prerequisites** | L3 complete, 6000 field hours |
| **Training Focus** | Advanced motor control, hazardous locations, UPS, estimating basics |
| **Certification** | Preparing for Journeyman exam |

**Technical Skills Expected (End of Year 4):**
- Advanced motor control and instrumentation
- Classified and hazardous installations
- UPS and similar components
- Harmonics, power factor testing and treatment
- Basic estimating procedures
- Comprehensive transformer/motor/VFD knowledge
- Lighting sources (efficiency, color, heat, layout)
- Basic lightning protection
- Service/feeder/branch circuit calculations
- Demand factors and derating
- Overhead line components
- Intrinsically safe circuits

---

### Level 5: Journeyman Electrician

| Attribute | Value |
|-----------|-------|
| **Level ID** | L5 |
| **Level Name** | Journeyman |
| **Typical Role** | Journeyman Electrician |
| **Prerequisites** | L4 complete, 8000 field hours, Journeyman license |
| **Training Focus** | Advanced technical, mentoring skills, NEC expertise |
| **Certification** | State Journeyman License, OSHA 10 (some states) |

**Role Focus:**
- All apprentice-level responsibilities
- Teaching, training, and mentoring apprentices
- Advanced knowledge in specialized areas (transformers, controls, PLCs, etc.)
- Industrial and commercial electrical work proficiency
- GSL SOP and lean construction proficiency
- Preparing for management opportunities

---

### Level 6: Lead Journeyman

| Attribute | Value |
|-----------|-------|
| **Level ID** | L6 |
| **Level Name** | Lead |
| **Typical Role** | Lead Journeyman |
| **Prerequisites** | L5 complete, demonstrated leadership ability |
| **Training Focus** | Small crew supervision, lean construction implementation |
| **Certification** | None additional (designation may be temporary) |

**Role Focus:**
- All journeyman functions
- Close supervision and training of small work crew
- Implementation of lean construction principles
- Personnel, administrative, and safety functions as directed by Foreman

---

### Level 7: Foreman

| Attribute | Value |
|-----------|-------|
| **Level ID** | L7 |
| **Level Name** | Foreman |
| **Typical Role** | Project Foreman |
| **Prerequisites** | L5 or L6 complete, GSL Safety Coordinator certification |
| **Training Focus** | Field Leadership (all sections), safety management, project controls |
| **Certification** | GSL Safety Coordinator, First Aid/CPR, OSHA 30 |

**Role Focus:**
- All journeyman functions
- Direct supervision of 7-10 employees
- Production, quality, and cost control
- Full implementation of GSL Safety and Loss Control Program
- Knowledge of all GSL SOPs
- Training, protecting, directing, and managing crew
- Project planning, scheduling, and documentation

**Required Training Completion:**
- Field Leadership Section 1 (Skills, Traits, Responsibilities)
- Field Leadership Section 2 (Anatomy of a Project)
- Field Leadership Section 3 (Leadership)
- Field Leadership Section 4 (Policy)
- Safety Coordinator Series (3.0-11.0)
- Lean Construction fundamentals

---

### Level 8: Project Superintendent (General Foreman)

| Attribute | Value |
|-----------|-------|
| **Level ID** | L8 |
| **Level Name** | Superintendent |
| **Typical Role** | Project Superintendent / General Foreman |
| **Prerequisites** | L7 complete, 3-5 years as Foreman |
| **Training Focus** | Multi-foreman supervision, critical path management, client relations |
| **Certification** | All L7 certifications |

**Role Focus:**
- Supervision of 2+ Foremen
- Monitoring critical path items
- Change order integration and schedule impact coordination
- Project manager/estimator interface
- Client relations development
- Invoice, report, and administrative paperwork

**Additional Training:**
- Advanced leadership courses
- Project management
- Managing sub-contractors

---

### Level 9: Project Safety Coordinator

| Attribute | Value |
|-----------|-------|
| **Level ID** | L9 |
| **Level Name** | Safety Specialist |
| **Typical Role** | Project Safety Coordinator |
| **Prerequisites** | L5+ complete, safety focus |
| **Training Focus** | Complete Safety Coordinator curriculum, OSHA regulations |
| **Certification** | GSL Safety Coordinator (full), OSHA 30, First Aid/CPR Instructor (recommended) |

**Role Focus:**
- Dedicated safety oversight for large projects
- Safety program implementation and enforcement
- Incident investigation and reporting
- OSHA/MSHA compliance
- Safety training delivery
