# Job Description to SOP Mapping

**Date:** 2026-01-17
**Purpose:** Map applicable SOPs to each Job Description for Phase 3 revisions

---

## Mapping Methodology

SOPs are mapped to Job Descriptions based on:
1. **Primary Responsibility (R)** - Role performs the SOP activities
2. **Accountability (A)** - Role is accountable for SOP outcomes
3. **Consulted (C)** - Role provides input to SOP activities
4. **Informed (I)** - Role needs awareness of SOP activities
