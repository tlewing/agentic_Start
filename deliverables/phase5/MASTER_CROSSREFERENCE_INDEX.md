## Maintenance

### Adding New SOPs
1. Assign SOP number per phase (9.X.XXX)
2. Add Training references using TRAINING_SOP_MAPPING.md
3. Add JD references using JD_SOP_MAPPING.md
4. Add MD references using MD_SOP_MAPPING.md
5. Update REVISED_SOP_LIST.md

### Adding New Training
1. Assign to appropriate Tab
2. Update TRAINING_SOP_MAPPING.md with applicable SOPs
3. Update skill level requirements in Phase 1 deliverables

### Updating Job Descriptions
1. Reference JD_SOP_MAPPING.md for applicable SOPs
2. Include skill level requirements
3. Reference applicable MDs

### Updating Management Directives
1. Reference MD_SOP_MAPPING.md for applicable SOPs
2. Update role requirements
3. Ensure bidirectional links in SOPs
