# Learn365 Skill Assignment Guide

**Courses in Learn365 with skill mappings: 50**
**Courses in CODE_REGISTRY not yet in Learn365: 130**

## How to Use

1. Open Learn365 Admin Center
2. Navigate to the course (use the L365 Code to find it)
3. Go to Course Settings > Skills
4. Add each skill listed below with the specified Awarded Level
5. Check the box when done

**Confidence key:** A = assessment-verified, B = content-verified, C = title-only match
