# SOP Development Project — Vision

## Purpose
Develop a complete, standardized set of Standard Operating Procedures (SOPs) for electrical contractor project management—from project turnover through closeout.

## Scope
- **Organization**: Electrical subcontractor operations
- **Coverage**: Full project lifecycle (pre-construction, execution, closeout)
- **Numbering**: 9.41.xxx series (Project Management)

## Goals
1. **Consistency** — Standardize PM practices across all projects and personnel
2. **Training** — Provide clear onboarding material for new PMs and field supervisors
3. **Risk Reduction** — Document best practices to prevent common project failures
4. **Scalability** — Enable growth without losing institutional knowledge

## Quality Standards
- Each SOP should be actionable, not theoretical
- Include specific tools/systems used (Procore, etc.)
- Define clear ownership (PM vs Field Supervisor vs Admin)
- Reference related SOPs where workflows connect
